# vienna-kernel-source

[🇬🇧 English](README.md) · 🇧🇷 Português

Fontes do kernel do **Motorola Edge 60 Neo** (`vienna`, XT2509-1, MT6878 / Dimensity 7400),
extraídas do release GPL oficial da Motorola. **Uma branch por tag de build.**

> Isto é um **espelho**, não um fork. Nada aqui foi modificado. O conteúdo é byte a byte o que a
> Motorola publicou, e os checksums abaixo permitem provar isso.

## Por que espelhar, se a Motorola já publica

A Motorola publica em **tarballs de release** no
[MotorolaMobilityLLC](https://github.com/MotorolaMobilityLLC/kernel-mtk/releases). Serve para compilar
uma vez, e para mais nada. Extraído em git, você ganha:

| | tarball | este espelho |
|---|---|---|
| busca de código do GitHub / `grep` | não | **sim** |
| **`git diff` entre duas ROMs** | não | **sim**, e é o ponto principal |
| blame, permalink de linha, fork, PR | não | **sim** |
| baixar só o que precisa | não (214 MB) | **sim** (`--depth 1`, uma branch) |

Diffar duas tags mostra exatamente o que a Motorola mudou entre dois releases de ROM. É a coisa mais
útil que este repo faz.

## Organização

Cada branch é uma tag de build e carrega **os dois** projetos de kernel daquela build, lado a lado:

```
<tag>/
├── kernel-mtk/                  # a árvore do kernel
└── kernel_device_modules-6.1/   # a árvore dos device modules
```

Os dois vêm da mesma tag do lado da Motorola, então uma branch é um conjunto completo de fontes.

## Nota sobre o `certs/mtk_signing_key.pem`

A árvore `kernel_device_modules-6.1` traz um arquivo que contém uma **chave privada**, com subject
`CN=Build time autogenerated kernel key` (gerada em 2022). Ele vai exatamente como a Motorola
publicou, e é espelhado aqui sem alteração, porque um espelho que edita o próprio conteúdo não pode
ser verificado contra os checksums acima.

Isto não é uma divulgação de falha. O arquivo está publicamente baixável na própria página de release
da Motorola desde que a tag existe. Está anotado aqui só para ninguém se assustar ao encontrá-lo, e
porque uma chave autogerada em build não é algo que se deva presumir exclusivo seu.

## Compilar
