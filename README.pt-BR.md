# vienna-kernel-source - `MMI-W1UIS36H.39-25-8`

[🇬🇧 English](README.md) · 🇧🇷 Português

Fontes GPL do kernel do **Motorola Edge 60 Neo** (`vienna`, XT2509-1, MT6878 / Dimensity 7400),
build **MMI-W1UIS36H.39-25-8** (Android 16), extraídas **verbatim** do release GPL oficial da Motorola. Nada aqui é
modificado; o conteúdo é byte a byte o que a Motorola publicou, e os checksums abaixo provam isso.

## O que tem nesta branch

```
kernel-mtk/                  # a árvore do kernel
kernel_device_modules-6.1/   # a árvore dos device modules
```

Os dois projetos vêm da mesma tag do lado da Motorola, então esta única branch é um conjunto de fontes
completo para a build `MMI-W1UIS36H.39-25-8`.

Release upstream de onde isto é espelhado:
[MotorolaMobilityLLC/kernel-mtk @ `MMI-W1UIS36H.39-25-8`](https://github.com/MotorolaMobilityLLC/kernel-mtk/releases/tag/MMI-W1UIS36H.39-25-8).

## Sobre `certs/mtk_signing_key.pem`

O `kernel_device_modules-6.1` traz uma **chave privada autogerada em build** (subject
`CN=Build time autogenerated kernel key`), exatamente como a Motorola publicou. É espelhada sem alteração,
porque um espelho que edita o conteúdo não bate com os checksums acima. Ela é publicamente baixável do
próprio release da Motorola desde que a tag existe.

## Baixar

```bash
git clone --branch MMI-W1UIS36H.39-25-8 --depth 1 https://github.com/VD171/vienna-kernel-source
```
