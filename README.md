# vienna-kernel-source

Kernel sources for the **Motorola Edge 60 Neo** (`vienna`, XT2509-1, MT6878 / Dimensity 7400),
extracted from Motorola's official GPL release. **One branch per build tag.**

> This is a **mirror**, not a fork. Nothing here is modified. The contents are byte for byte what
> Motorola published, and the checksums below let you prove it.

## Why a mirror, when Motorola already publishes it

Motorola publishes these as **release tarballs** on
[MotorolaMobilityLLC](https://github.com/MotorolaMobilityLLC/kernel-mtk/releases). That is fine for
building once, and useless for everything else. Extracted into git you get:

| | tarball | this mirror |
|---|---|---|
| GitHub code search / `grep` | no | **yes** |
| **`git diff` between two ROM versions** | no | **yes**, and it is the whole point |
| blame, line permalinks, fork, PR | no | **yes** |
| fetch only what you need | no (214 MB) | **yes** (`--depth 1`, one branch) |

Diffing two tags shows exactly what Motorola changed between two ROM releases. That is the single
most useful thing this repo does.

## Layout

Each branch is one build tag and holds **both** kernel projects for that build, side by side:

```
<tag>/
├── kernel-mtk/                  # the kernel tree
└── kernel_device_modules-6.1/   # the device modules tree
```

Both come from the same tag name on Motorola's side, so one branch is one complete source set.

## Note on `certs/mtk_signing_key.pem`

The `kernel_device_modules-6.1` tree ships a file that contains a **private key**, with subject
`CN=Build time autogenerated kernel key` (generated 2022). It is shipped exactly as Motorola
published it, and it is mirrored here unchanged, because a mirror that edits its contents cannot be
verified against the checksums above.

This is not a disclosure. The file has been publicly downloadable from Motorola's own release page
for as long as the tag has existed. It is called out here only so nobody is surprised to find it,
and because a build-time autogenerated key is not something you should assume is unique to you.
