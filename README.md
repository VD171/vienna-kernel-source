# vienna-kernel-source - `MMI-W1UI36H.39-25-11-4`

🇬🇧 English · [🇧🇷 Português](README.pt-BR.md)

Motorola GPL kernel sources for the **Motorola Edge 60 Neo** (`vienna`, XT2509-1, MT6878 / Dimensity 7400),
build **MMI-W1UI36H.39-25-11-4** (Android 16, kernel 6.1.157), extracted **verbatim** from Motorola's official GPL release. Nothing here is
modified; the contents are byte for byte what Motorola published, and the checksums below prove it.

## What is in this branch

```
kernel-mtk/                  # the kernel tree
kernel_device_modules-6.1/   # the device modules tree
```

Both projects come from the same tag on Motorola's side, so this single branch is one complete source set
for build `MMI-W1UI36H.39-25-11-4`.

## Note on `certs/mtk_signing_key.pem`

`kernel_device_modules-6.1` ships a **build-time autogenerated private key** (subject
`CN=Build time autogenerated kernel key`), exactly as Motorola published it. It is mirrored unchanged,
because a mirror that edits its contents cannot be verified against the checksums above. It has been
publicly downloadable from Motorola's own release for as long as the tag has existed.
